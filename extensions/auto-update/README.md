# Автообновление сборки

При `session_start` в интерактивном Pi расширение запускает команду сборки,
если после успешного обновления прошло не меньше 7 дней. Без сохранённой
даты первая проверка сразу запускает обновление. RPC и print пропускаются.
Фонового таймера и cron нет; проверка также возможна после `/reload` или смены
сессии, но интервал остаётся общим для всех сессий.

Команда эквивалентна команде установки из корневого README с дополнительными
`--agent-dir <каталог Pi>` и `--no-launch`. Она выполняется без shell,
с закрытым stdin и лимитом 10 минут. Startup ожидает её завершения.
Расширение работает только при существующем профиле `home` или `work`.
Установщик рабочего профиля по-прежнему требует чистый checkout на `main`;
расширение не делает stash, reset или commit.

Состояние хранится в `<agentDir>/pi-config-update-state.json`, вне Git:
`lastSuccessAt` задаёт недельный интервал, `lastAttemptAt` — суточную паузу
после неудачи. Запись атомарная. Успешная полная ручная установка/обновление
новым CLI тоже обновляет даты; `--dry-run` и `--skip-install` — нет.
Повреждённое состояние блокирует автообновление с предупреждением.

`<agentDir>/pi-config-update.lock` не допускает параллельные автообновления.
Блокировка снимается в `finally`, при штатном завершении сессии процесс
отменяется. После принудительного убийства процесса файл может остаться:
проверьте PID внутри файла и отсутствие работающего установщика, затем
удалите lock вручную. По возрасту lock не удаляется, чтобы не прервать
медленное живое обновление. Ручной установщик эту блокировку не использует:
не запускайте его одновременно с автообновлением.

Результат показывается уведомлением, вывод установщика не передаётся модели.
Для диагностики ошибки запустите команду вручную. Новые ресурсы и runtime
применяются после перезапуска Pi; расширение не перезагружает сессию само.
Само включение расширения разрешает автоматическое выполнение установщика,
включая загрузку актуальных исходников и обновление управляемых пакетов.
Отключить можно через настройки ресурсов Pi, исключив `auto-update`.
