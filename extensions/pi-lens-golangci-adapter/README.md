# Адаптер Pi Lens для golangci-lint v2

Временный общий обход несовместимости runner Pi Lens **4.3.0** с golangci-lint v2.

При `session_start` автоматически исправляет установленный npm-пакет в каталоге агента: `dist/index.js` и `dist/clients/dispatch/runners/golangci-lint.js`. Проверяет версию и точную сигнатуру обоих файлов до записи; повторное применение ничего не меняет. Другие версии пакета не затрагивает.

Исправленный runner определяет версию линтера при запуске: для v2 включает чистый JSON без статистики, для v1 сохраняет прежние аргументы. `PATH` и конфигурация проектов не меняются. Новых зависимостей нет.

После первого применения (в том числе после переустановки Pi Lens) нужен `/reload` или перезапуск. При неизвестной сигнатуре выводится предупреждение без перезаписи файлов. После upstream-исправления следует обновить закреплённую версию Pi Lens и удалить этот компонент.

Проверка: `node --test extensions/pi-lens-golangci-adapter/adapter.test.mjs`.
