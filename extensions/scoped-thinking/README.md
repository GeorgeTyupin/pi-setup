# Scoped thinking

`/scoped-thinking` открывает список режимов для переключения через `Shift+Tab`:

- `Enter` / `Space` — включить или выключить режим;
- `Ctrl+S` — сохранить; `Esc` — отменить изменения;
- хотя бы один режим должен остаться выбранным.

Можно задать список командой, в том числе его порядок:

```text
/scoped-thinking medium high xhigh
/scoped-thinking all
```

Выбор сохраняется в `scoped-thinking.json` в каталоге агента Pi и действует
между сессиями и проектами. До первой настройки доступны все режимы.
При переключении пропускаются режимы, не поддерживаемые текущей моделью.
Если пересечение пустое, уровень не меняется и выводится предупреждение.
Если текущий режим вне scope, переключение начинает с первого доступного.
Сохранение scope само по себе не меняет текущий уровень.

`/thinking` остаётся обычным ручным выбором, не ограниченным scope.
В RPC / print можно задать scope аргументами команды; интерактивный список
работает только в TUI.

Перехват происходит в редакторе, до встроенного `app.thinking.cycle`, а не
через `registerShortcut`: Pi запрещает переопределять это действие таким способом.
Переназначение `app.thinking.cycle` учитывается; диалоги не перехватываются.
Существующий редактор `compact-footer` / `inline-skill-autocomplete` сохраняется:
расширения координируются событиями `pi-config:editor-created` и `pi-config:editor-query`.

Новых runtime-зависимостей нет. Для подключения после установки — `/reload`.
