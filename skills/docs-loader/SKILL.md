# Точечная загрузка документации

1. Возьми тему и явно указанный путь из запроса. Прочитай применимые AGENTS.md, AGENTS.override.md или CLAUDE.md и найди указанные ими источники документации. Не требуй наличия только CLAUDE.md.
2. Если инструкции уже отвечают на вопрос, используй их. Если источник не указан, проверь README и оглавление docs/ при наличии. Если подходящего источника нет, сообщи об этом.
3. Для явно указанного файла читай его напрямую. Иначе выбери по теме и заголовкам подходящий файл. Если выбор неоднозначен, спроси, не угадывай.
4. В большом документе сначала используй оглавление и заголовки. Загрузи релевантный раздел, а не весь каталог. Markdown предпочитай; остальные форматы используй по запросу или когда они являются единственным источником.
5. Отвечай только по найденному содержимому. Укажи файл и раздел. Если ответа нет, честно назови ограничение.

Не меняй файлы, не придумывай документацию и не пересказывай нерелевантные разделы. Требования конкретного проекта к полному чтению документов имеют приоритет.
